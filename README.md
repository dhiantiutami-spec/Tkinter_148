Kode ini digunakan untuk membuat aplikasi sederhana menggunakan Tkinter di Python untuk memprediksi program studi pilihan. `import tkinter as tk` digunakan untuk memanggil library Tkinter, sedangkan fungsi `prediksi_prodi()` menampilkan hasil prediksi berupa Teknologi Informasi ketika tombol diklik. Variabel `root` digunakan untuk membuat jendela aplikasi dengan judul, ukuran 500×600, dan warna latar tertentu. Selanjutnya, `Label` digunakan untuk menampilkan judul dan keterangan, `Frame` untuk mengelompokkan bagian input, serta perulangan `for` untuk membuat 10 kolom input nilai mata pelajaran menggunakan `Entry`. Tombol `Button` berfungsi menjalankan fungsi prediksi, lalu `hasil_label` menampilkan hasilnya. Terakhir, `root.mainloop()` digunakan agar jendela aplikasi tetap berjalan. Namun, prediksi pada kode ini masih tetap Teknologi Informasi dan belum menghitung nilai yang dimasukkan pengguna.
